# Phishing URL Detection Using an Optimized Decision Tree Classifier

A university Data Mining project that reproduces and extends an existing
phishing-detection project using the Decision Tree classification algorithm.

## Project Objective

The objective of this project is to classify URLs as phishing or legitimate
using features that can be extracted safely from URL text.

## Primary Algorithm

Decision Tree Classifier

## Dataset

UCI PhiUSIIL Phishing URL Dataset

## Planned Final Output

A Streamlit dashboard that allows a user to enter a URL and view:

- Phishing or legitimate prediction
- Model confidence
- Risk level
- Extracted URL features
- Model observations

## Safety

The application analyses submitted URLs only as text. It does not open, visit,
request, download from, or connect to the submitted website.

## Project Status

Project initialization in progress.
