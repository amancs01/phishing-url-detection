# URL-Only Feature Selection

This project's final prediction flow must be:

Raw URL string -> safe local text parsing -> numerical URL features ->
Decision Tree -> prediction

Training-time features and dashboard-time features must be produced by the same
extractor. This prevents the model from learning columns that were available in
the PhiUSIIL dataset but cannot be recreated when a user pastes a new URL into
the Streamlit dashboard.

## Sources Inspected

The feature set below was selected after inspecting:

- The actual PhiUSIIL columns in `results/dataset_schema.json`
- The validation report in `results/data_validation.json`
- `docs/dataset_schema.md`
- The EDA notebooks in `notebooks/01_dataset_exploration.ipynb` and
  `notebooks/02_url_feature_analysis.ipynb`

The dataset contains several useful-looking URL columns, but the final model
will use features generated by our own local URL parser rather than copying
PhiUSIIL's precomputed feature columns.

## Final Feature Set

The exact feature order is defined in `src/feature_definitions.py` as
`FEATURE_NAMES`.

| Feature | Meaning | Extraction method | Why safe |
| --- | --- | --- | --- |
| `url_length` | Number of characters in the stripped URL text. | Use `len()` on the stripped raw input. | Uses only the submitted text. |
| `domain_length` | Number of characters in the parsed hostname. | Parse locally and count hostname characters. | Does not resolve or contact the domain. |
| `path_length` | Number of characters in the URL path. | Parse locally with `urllib.parse`. | Path text is part of the URL string. |
| `query_length` | Number of characters after the `?` query separator. | Parse locally with `urllib.parse`. | Query text is part of the URL string. |
| `number_of_dots` | Count of `.` characters in the stripped URL text. | String count. | Local character counting only. |
| `number_of_hyphens` | Count of `-` characters. | String count. | Local character counting only. |
| `number_of_underscores` | Count of `_` characters. | String count. | Local character counting only. |
| `number_of_slashes` | Count of `/` characters. | String count. | Local character counting only. |
| `number_of_question_marks` | Count of `?` characters. | String count. | Local character counting only. |
| `number_of_equal_signs` | Count of `=` characters. | String count. | Local character counting only. |
| `number_of_at_symbols` | Count of `@` characters. | String count. | Local character counting only. |
| `number_of_ampersands` | Count of `&` characters. | String count. | Local character counting only. |
| `number_of_percent_symbols` | Count of `%` characters. | String count. | Local character counting only. |
| `number_of_digits` | Count of numeric characters. | Sum `character.isdigit()` over the stripped URL text. | Local character counting only. |
| `number_of_letters` | Count of alphabetic characters. | Sum `character.isalpha()` over the stripped URL text. | Local character counting only. |
| `digit_ratio` | Share of URL characters that are digits. | `number_of_digits / url_length`, or `0` for empty input. | Derived only from local counts. |
| `letter_ratio` | Share of URL characters that are letters. | `number_of_letters / url_length`, or `0` for empty input. | Derived only from local counts. |
| `special_character_count` | Count of characters that are not letters, digits, or whitespace. | Local character classification. | No external lookup is needed. |
| `number_of_subdomains` | Number of hostname labels before the registered-looking domain and suffix. | Split hostname text on dots and count labels before the final two labels. | Uses hostname text only; no DNS lookup. |
| `domain_is_ip` | Whether the hostname text is an IPv4 or IPv6 literal. | Use Python's `ipaddress.ip_address()` on the hostname text. | Checks text format only and never resolves names. |
| `uses_https_text` | Whether the URL string begins with or parses as HTTPS. | Check the parsed scheme after local parsing. | This does not inspect TLS certificates or website security. |
| `has_port` | Whether the URL text includes an explicit port. | Use parsed netloc/port handling locally. | Does not connect to the host or port. |
| `number_of_query_parameters` | Number of query parameters in the URL. | Parse the query string locally with `urllib.parse.parse_qsl`. | Query parameters are part of the URL text. |
| `suspicious_keyword_count` | Count of selected phishing-related words in the lowercased URL text. | Count keywords from the centralized `SUSPICIOUS_KEYWORDS` list. | Plain-text matching only. |
| `has_suspicious_keyword` | Whether any suspicious keyword is present. | Convert the keyword count to `0` or `1`. | Plain-text matching only. |
| `known_shortener_domain` | Whether the hostname matches a small known URL-shortener list. | Compare lowercased hostname text with `KNOWN_SHORTENER_DOMAINS`. | Uses a hardcoded local list; no shortening service is queried. |

## Centralized Keyword and Shortener Lists

The initial suspicious keyword list is:

`login`, `verify`, `account`, `secure`, `update`, `signin`, `password`,
`bank`, and `confirm`.

The initial known-shortener list is:

`bit.ly`, `cutt.ly`, `goo.gl`, `is.gd`, `ow.ly`, `rebrand.ly`,
`tinyurl.com`, and `t.co`.

These lists are intentionally small and explainable for a university Data
Mining project. They can be revised later if documentation justifies the
change.

## PhiUSIIL Features Excluded From the Final Dashboard Model

The following PhiUSIIL columns appear to require webpage content, browser-like
inspection, redirects, page resources, forms, or link analysis. They are
excluded from the final URL-only feature set:

- `LineOfCode`
- `LargestLineLength`
- `HasTitle`
- `Title`
- `DomainTitleMatchScore`
- `URLTitleMatchScore`

- `Robots`
- `IsResponsive`
- `NoOfURLRedirect`
- `NoOfSelfRedirect`
- `HasDescription`
- `NoOfPopup`
- `NoOfiFrame`
- `HasExternalFormSubmit`
- `HasSocialNet`
- `HasSubmitButton`
- `HasHiddenFields`
- `HasPasswordField`
- `HasCopyrightInfo`
- `NoOfImage`
- `NoOfCSS`

are not yet verified closely enough to guarantee that the dashboard can
reproduce them in the same way.

## Notes on Similar PhiUSIIL Feature Names

Several selected features resemble PhiUSIIL columns, such as `url_length`
versus `URLLength`, `domain_length` versus `DomainLength`, and
`uses_https_text` versus `IsHTTPS`. Later modeling must still use our extracted
columns, not the original PhiUSIIL columns, because the final dashboard will
only have access to a raw submitted URL string.

`uses_https_text` means only that the URL text uses the HTTPS scheme. It does
not mean the website has a valid TLS certificate.

`domain_is_ip` means the hostname text itself is an IP literal. It must never
be calculated by resolving a domain name.
