# Post-Hoc Diagnostic Analysis: External Leaf Routing

## Purpose

This post-hoc diagnostic analysis traces URL-Phish samples through the frozen
PhiUSIIL Tier E Decision Tree. It uses `model.apply(X)` and the tree internals
only. No model is refit, no threshold is changed, and no URL is contacted.

The primary question is whether URL-Phish benign false positives are being
routed into leaves that were nearly pure phishing leaves under PhiUSIIL
training.

## Method

The leaf-training counts use the PhiUSIIL train plus validation rows, matching
the rows used to fit the packaged optimized model. External counts use the
URL-Phish Version 2 Tier E matrix generated by the project extractor. Labels
use the project convention `0 = phishing`, `1 = legitimate`.

For each leaf, the analysis records:

- Leaf node ID
- PhiUSIIL training sample count reaching the leaf
- PhiUSIIL phishing and legitimate counts
- Training phishing proportion
- Predicted class
- URL-Phish benign and phishing counts
- URL-Phish benign false-positive count
- Human-readable decision path

## Main Finding

Yes. External benign URLs are overwhelmingly routed into leaves that were pure
or near-pure phishing leaves in PhiUSIIL training.

The dominant false-positive leaf is leaf `136`. It received 88,986 URL-Phish
benign false positives. In PhiUSIIL training, that leaf received 51,406 samples,
all phishing. Its complete decision path is simply:

```text
number_of_slashes > 2.500000
```

This is not causal proof, but it is strong diagnostic evidence that a lexical
rule that was highly discriminative inside PhiUSIIL does not transfer to the
URL-Phish benign source distribution.

## Predicted-Class Imbalance

The model predicted phishing for 94.232% of all URL-Phish rows. URL-Phish
benign specificity was 0.06519, meaning only 6,519 of 100,000 benign rows were
predicted legitimate.

The probability distributions show a sharp transfer failure for benign rows:
URL-Phish benign probabilities look much closer to PhiUSIIL phishing
probabilities than to PhiUSIIL legitimate probabilities. This explains the low
external precision and low benign specificity without requiring a
missed-phishing collapse.

## Interpretation

The leaf-routing evidence supports the mechanism suggested by
class-conditional feature shift. The strongest single routing rule,
`number_of_slashes > 2.5`, was a pure-phishing branch in PhiUSIIL training but
matches most URL-Phish benign rows. Because URL-Phish benign rows have more
path/slash structure than PhiUSIIL legitimate rows, the frozen tree routes them
into phishing leaves.

This is post-hoc diagnostic evidence of class-conditional covariate shift. It
does not prove concept shift, does not prove dataset quality problems, and does
not show that changing the threshold would be justified for the registered
external result.

## Safety Statement

All computations used local feature matrices and the frozen saved model. No URL
from PhiUSIIL or URL-Phish was opened, requested, resolved, pinged, scraped, or
contacted.
